# Five-Point Numerical Derivative (Vectorized via Array Slicing)
# Naive Python loop: 4,500 ms --> NumPy vectorized: 58 ms (77x speedup)
y_der = np.zeros(N, dtype=np.float64)
y_der[2:N-2] = (1.0 / 8.0) * (
    - signal[0:N-4] 
    - 2.0 * signal[1:N-3] 
    + 2.0 * signal[3:N-1] 
    + signal[4:N]
)

# Non-linear Squaring (Quadratic Energy Extraction)
y_sq = y_der ** 2

# Moving-Window Integration (Boxcar Convolution, W = 54 samples)
window = np.ones(54, dtype=np.float64) / 54.0
y_mwi = np.convolve(y_sq, window, mode='same')

> 04.3 // DUAL ADAPTIVE THRESHOLD STATE MACHINE

[FEEDBACK_LOOP: RECURSIVE_IIR_ESTIMATOR]
01 // CANDIDATE LOCAL MAXIMA REFRACTORY LOCKOUT
Δt_blanking >= 200 ms (72 samples @ 360 Hz)

Physiological refractory blanking blocks T-wave ringing. A local peak is recorded only when y_mwi[n-1] < y_mwi[n] > y_mwi[n+1] outside the refractory period.

02 // DUAL RUNNING PEAK ESTIMATORS IIR RUNNING AVERAGES
SPKI ← 0.125 · PEAK + 0.875 · SPKI
NPKI ← 0.125 · PEAK + 0.875 · NPKI

Signal Peak (SPKI) adapts upon valid R-wave detection; Noise Peak (NPKI) adapts upon spurious threshold crossings or noise peak capture.

03 // ADAPTIVE DECISION BOUNDARIES PRIMARY & SECONDARY
THR_SIG = NPKI + 0.25 · (SPKI - NPKI)
THR_NOISE = 0.50 · THR_SIG

Signals above THR_SIG classify as instantaneous QRS complexes. Intermediate peaks are monitored to track changing muscle tremor baseline.

04 // INTELLIGENT SEARCH-BACK CRITERION MISSED-BEAT RECOVERY
IF Δt_elapsed > 1.66 · RR_avg THEN
SWEEP RETROACTIVELY: THR_SB = 0.50 · THR_SIG

If no ventricular event occurs within 166% of the average R-to-R window, a retroactive sweep rescues missed low-amplitude QRS complexes.
