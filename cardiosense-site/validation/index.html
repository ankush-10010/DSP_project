> 06.4 // AAMI EC57 EVALUATION CRITERIA

AAMI ±150 MS WINDOW § 4.2.1

Under Association for the Advancement of Medical Instrumentation (AAMI) standard EC57, a detected beat is certified as a True Positive (TP) if and only if:

|t_detected - t_reference| <= 150 ms
(Δn <= 54 samples @ 360 Hz)

A greedy 1-to-1 matching algorithm prevents duplicate assignments. Unmatched detections are scored as False Positives (FP); unmatched annotations are scored as False Negatives (FN).

CONVERGENCE: GREEDY TEMPORAL PROXIMITY
METRIC DEFINITIONS FORMULATION
Sensitivity (Se):
Se = TP / (TP + FN)
Positive Predictivity (PPV):
PPV = TP / (TP + FP)
F1-Score Harmonic Mean:
F1 = 2 * (Se * PPV) / (Se + PPV)
Detection Error Rate (DER):
DER = (FP + FN) / Total_Ref_Beats
AAMI STANDARD FORMULARY // EC57:1998
