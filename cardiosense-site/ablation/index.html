> 07.1 // EXPERIMENT 01: MWI WINDOW SENSITIVITY (50 - 250 MS)
METRIC: PRECISION / RECALL TRADEOFF
psychology ELECTROPHYSIOLOGICAL RATIONALE & BOUNDARY CONDITIONS

The QRS complex represents ventricular depolarization with normal physiological duration spanning 70–110 ms (widening to 120–150 ms in ventricular ectopy, PVCs, and bundle branch block). Moving window integration smooths the rectified derivative signal into an envelope. If W < 100 ms, biphasic or notched R-peaks segment into multiple disjoint pulses, provoking dual-count false positives. Conversely, ventricular repolarization (T-wave) spans 150–250 ms. When W ≥ 200 ms, the integration envelope bleeds across the S-T segment into the ascending T-wave, blinding the adaptive threshold comparator and driving runaway false positive explosions.

> 07.3 // EXPERIMENT 03: CAUSAL PHASE DELAY QUANTIFICATION
PROTOCOL: LFILTER VS FORWARD-BACKWARD FILTFILT
functions MATHEMATICAL DERIVATION: GROUP DELAY τ_g(ω)
SAMPLING RATE f_s = 360 HZ

A causal digital filter introduces phase distortion parameterized by group delay τ_g(ω) = -dθ(ω)/dω. For the second-order Butterworth IIR bandpass filter cascaded in the Pan-Tompkins pipeline, the causal impulse response shifts peak fiducial locations downstream:

CAUSAL IMPLEMENTATION (scipy.signal.lfilter) τ_g(10 Hz) = 15.03 samples = 41.75 ms
τ_g(12 Hz) = 18.18 samples = 50.50 ms

Systematic asymmetric delay shifts all detected R-peaks downstream in time.

ZERO-PHASE IMPLEMENTATION (scipy.signal.filtfilt) θ_{eff}(ω) = θ(ω) - θ(ω) = 0.00 radians
τ_g(ω) = 0.00 ms (True Zero-Phase)

Forward-backward bidirectional filtering doubles order while cancelling phase completely.
