> 02.1 // MATHEMATICAL FORMULATIONS

[KERNEL KINEMATICS]
dsp_transform_equations.txt
ENCODING: UTF-8 // C-SYMBOLS
[STAGE 1: DISCRETE BANDPASS FILTER (5 - 15 HZ)]
H_BP(s) = ( (ω0 / Q) * s ) / ( s^2 + (ω0 / Q)*s + ω0^2 )
y_bp[n] = b0*x[n] + b1*x[n-1] + b2*x[n-2] - a1*y_bp[n-1] - a2*y_bp[n-2]
Zero-phase bidirectional recursion (scipy.signal.filtfilt). Phase response: θ(ω) = 0 radians.
[STAGE 2: FIVE-POINT NUMERICAL DERIVATIVE]
y_der[n] = (1/8) * [ -x[n-2] - 2*x[n-1] + 2*x[n+1] + x[n+2] ]
Transfer Function: H_der(z) = (1/8) * [ -z^(-2) - 2*z^(-1) + 2*z^1 + z^2 ]
Slope approximation suppress low-frequency baseline drifts while amplifying high-velocity QRS slopes.
[STAGE 3: NON-LINEAR QUADRATIC OPERATOR]
y_sq[n] = ( y_der[n] )^2
Point-wise rectification and non-linear amplification of large QRS spikes; suppresses false P and T waves.
[STAGE 4: MOVING WINDOW INTEGRATION (MWI)]
y_mwi[n] = (1 / 54) * sum_{k=0}^{53} y_sq[n - k] (W = 150 ms, N = 54 samples at 360 Hz)
Smooths high-frequency spikes into uniform energy envelopes corresponding to ventricular depolarizations.
[STAGE 5: DUAL ADAPTIVE THRESHOLD RECURSION]
SPKI <-- 0.125 * PEAK + 0.875 * SPKI
NPKI <-- 0.125 * PEAK + 0.875 * NPKI
THR_SIG = NPKI + 0.25 * (SPKI - NPKI)
THR_NOISE = 0.50 * THR_SIG
THR_SB = 0.50 * THR_SIG (if Δt > 1.66 * RR_avg)
tau_ref = 200 ms (72 samples at 360 Hz blanking period)
